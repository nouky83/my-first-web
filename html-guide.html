HTML을 전혀 몰라도 괜찮습니다. 이 페이지를 위에서부터 차근차근 읽어 보세요.

1. HTML이란?

HTML은 웹페이지의 내용과 구조를 만드는 언어입니다.

집 짓기에 비유하면 이렇습니다.

  • HTML = 집의 뼈대 (벽, 방, 문). 무엇이 어디에 있는지를 정합니다.
  • CSS = 인테리어 (색, 크기, 배치). 어떻게 보일지를 정합니다.
  • JavaScript = 전기와 수도 (움직임, 반응). 어떻게 동작할지를 정합니다.

지금은 HTML을 배웁니다. 이 페이지의 꾸밈(색, 글꼴, 상자 모양)은 style.css 파일에 따로 모아 두었으니, CSS가 궁금해지면 그 파일을 열어 보세요.

2. 태그란?

HTML은 태그로 이루어집니다. 태그는 "이 글자는 제목이야", "이건 문단이야"처럼 내용에 이름표를 붙이는 것입니다.

태그는 보통 여는 태그와 닫는 태그가 한 쌍입니다.

<p>안녕하세요</p>
 ↑      ↑       ↑
여는태그  내용   닫는태그 (앞에 / 가 붙음)

어떤 태그는 내용이 없어서 닫는 태그가 없습니다. 예: 줄바꿈 <br>, 가로줄 <hr>, 이미지 <img>

태그에는 속성을 붙여 추가 정보를 줄 수 있습니다. 속성은 이름="값" 형태로 여는 태그 안에 씁니다.

<a href="https://www.google.com">구글</a>
   ↑
   속성: 링크가 어디로 갈지 알려줌

3. HTML 문서의 기본 뼈대

모든 HTML 파일은 아래와 같은 모양으로 시작합니다. 외울 필요 없이, 복사해서 쓰면 됩니다.

<!DOCTYPE html>          ← "이건 HTML 문서야"라는 선언
<html lang="ko">         ← HTML 시작 (한국어 문서)
<head>                   ← 보이지 않는 설정 정보
    <meta charset="UTF-8">   ← 한글이 깨지지 않게 하는 설정
    <title>페이지 제목</title> ← 브라우저 탭에 표시되는 제목
</head>
<body>                   ← 여기부터 화면에 보이는 내용
    <h1>안녕하세요</h1>
</body>
</html>                  ← HTML 끝

지금 이 브라우저 탭 위쪽을 보세요. "HTML 처음 배우기"라고 쓰여 있죠? 그게 <title>입니다.

4. 제목과 문단

제목은 <h1>부터 <h6>까지 6단계가 있습니다. 숫자가 작을수록 큰 제목입니다.

코드:

<h1>가장 큰 제목</h1>
<h2>두 번째 제목</h2>
<h3>세 번째 제목</h3>
<p>이것은 문단입니다.</p>
<p>첫째 줄<br>둘째 줄</p>

결과:

가장 큰 제목

두 번째 제목

세 번째 제목

이것은 문단입니다.

첫째 줄
둘째 줄

알아둘 점: HTML 코드에서 엔터를 여러 번 쳐도 화면에서는 줄이 바뀌지 않습니다. 줄을 바꾸려면 <br>을 쓰거나 새 <p>를 만들어야 합니다.

5. 글자 꾸미기

코드 결과 뜻
<b>굵게</b> 굵게 bold
<i>기울임</i> 기울임 italic
<u>밑줄</u> 밑줄 underline
<mark>형광펜</mark> 형광펜 강조 표시
H<sub>2</sub>O H2O 아래 첨자
x<sup>2</sup> x2 위 첨자

6. 목록

목록은 두 종류가 있습니다. 목록 안의 각 항목은 <li>(list item)로 씁니다.

순서 없는 목록 (ul = unordered list)

<ul>
    <li>사과</li>
    <li>바나나</li>
</ul>

결과:

  • 사과
  • 바나나

순서 있는 목록 (ol = ordered list)

<ol>
    <li>일어나기</li>
    <li>세수하기</li>
</ol>

결과:

  1. 일어나기
  2. 세수하기

7. 링크

링크는 <a> 태그로 만듭니다. href 속성에 이동할 주소를 씁니다.

<a href="https://www.naver.com">네이버로 가기</a>
<a href="https://www.naver.com" target="_blank">새 탭에서 네이버 열기</a>
<a href="index.html">내 첫 페이지로 가기</a>
<a href="#what">이 페이지의 1번 항목으로 가기</a>

결과: (직접 눌러 보세요)

네이버로 가기

새 탭에서 네이버 열기

내 첫 페이지로 가기 (같은 폴더의 index.html)

이 페이지의 1번 항목으로 가기

8. 이미지

이미지는 <img> 태그로 넣습니다. 닫는 태그가 없습니다.

<img src="cat.jpg" alt="고양이 사진" width="300">
  • src: 이미지 파일 위치 (같은 폴더에 cat.jpg가 있어야 함)
  • alt: 이미지를 불러오지 못했을 때 대신 보여줄 설명
  • width: 이미지 너비 (픽셀)

결과: 이 폴더에는 cat.jpg가 없어서, 그림 대신 alt 글자가 보입니다.

"my first web" 폴더에 cat.jpg라는 사진을 넣고 새로고침(F5)하면 진짜 사진이 나타납니다.

9. 표

표는 여러 태그를 조합해서 만듭니다.

  • <table>: 표 전체
  • <tr>: 한 줄 (table row)
  • <th>: 제목 칸 (table header, 굵게 표시됨)
  • <td>: 일반 칸 (table data)
<table border="1">
    <tr>
        <th>이름</th>
        <th>나이</th>
    </tr>
    <tr>
        <td>철수</td>
        <td>20</td>
    </tr>
    <tr>
        <td>영희</td>
        <td>22</td>
    </tr>
</table>

결과:

이름 나이
철수 20
영희 22

10. 주석

주석은 화면에 보이지 않는 메모입니다. 코드에 설명을 남길 때 씁니다.

<!-- 이 글은 화면에 보이지 않습니다 -->

이 페이지의 소스(Ctrl+U)를 보면 주석이 곳곳에 달려 있습니다. 화면에는 안 보이지만 소스에는 있죠.

11. 직접 해보기

읽기만 하는 것보다 직접 고쳐 보는 게 가장 빨리 배우는 방법입니다.

  1. Cursor에서 index.html 파일을 엽니다.
  2. <h1>안녕하세요!</h1>의 글자를 자기 이름으로 바꿉니다.
  3. 저장합니다 (Ctrl+S).
  4. 브라우저에서 index.html을 새로고침(F5)해서 바뀐 걸 확인합니다.
